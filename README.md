# 五面板專業技術分析系統

## 執行方式
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 面板對應說明
| 面板 | 原圖表功能 | 本App實作方式 |
|---|---|---|
| 1 | K線形態＋GCAND趨勢緞帶＋型態標註 | 四色K線分類 ＋ 短均/中均緞帶 ＋ 費氏均線扇形 ＋ 四種自動標註型態 |
| 2 | 技術專家(TE) | 隨機指標KD情緒柱 ＋ 中期上漲/下跌趨勢線 |
| 3 | 主力/散戶籌碼(MCDX) | MFI資金流量指標代理主力(鯨魚)力度 ＋ 短期/中期買訊線 |
| 4 | MACD | 標準 MACD(12,26,9) |
| 5 | RSI | RSI(9)/RSI(14)/RSI(24) |

## 面板1 自動標註的四種型態
- **賣出訊號**：高檔區均線糾結收斂
- **波動性凹陷(築底)**：低檔區波動急縮到近期最低
- **趨勢反轉燭**：爆量長K棒，方向與過去5日趨勢相反
- **急漲前紅K**：看漲反轉K線且未來3根K棒漲幅>3%（歷史回顧標註，非即時訊號）

⚠️ 面板1、2、3 為原廠黑箱指標(GCAND/TE/MCDX)的可驗證公開演算法替代方案，判讀邏輯一致但數值不會與原軟體逐一對應，僅供參考，非投資建議。
